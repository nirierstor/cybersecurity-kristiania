# TK1104 - Digital Technology

Introduction to digital technology and its fundamentals.

## Assignments

Assignments are graded either A-F or Pass/Fail.

- Assignment 1: Multiple choice test with 15 questions in person covering
  number systems (binary, hex and two's complement), text and multimedia representation, 
  and how the machine computes. No files published.  GRADE: Pass.

- [Assignment 2](assignments/assignment-2/): Group assignment (hands-on, in a Linux virtual machine) on Linux, email (SMTP),
  FTP and packet analysis, documented with annotated screenshots.
  - **Linux Terminal:** Created and navigated folders, wrote and appended to files with redirection, printed file
      contents and copied files.
  - **SMTP and Wireshark:** Captured traffic on the local MailHog test server. Analysed the TCP handshake, flags,
      the message data and the SMTP replay codes, and the packets that close the connection.
  - **FTP:** Transferred a file from a public FTP test server and captured the session in Wireshark.
  - **Protocol layers:** Identified the application, transport and network layer in captured packet, including protocols,
    ports, TCP flags, IP addresses and header length.
  - **TCP header:** Filled in the TCP header fields from a real packet.
  - **Presentation:** Presented our findings to other groups and supervisors.
