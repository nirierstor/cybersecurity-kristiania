# PRO105 - Creative Webproject

Creative web project course focused on building websites with HTML and CSS.

## Assignments

Assignments are graded A-F or Pass/Fail.

- [Assignment 1](assignments/assignment-1/website/): Individual assignemnt on the theme of outer space. Built a two-page
  website about black holes using only HTML and CSS: a landing page and a main page linked together.
  - **Planning:** Sketched both pages before coding (see `dokumenter`).
  - **Layout:** Flexbox for the main layout, with relative and absolute positioning.
  - **Interaction and animation:** Hover and focus effects, transitions and `@keyframes`animations, including a rocket
    animation on the landing page.
  - **Code standards:** Followed a code-standards table and semantic HTML (header, nav, main, footer).
  - **Contraints:** No JavaScript, no frameworks, and only an approved list of HTML tags and CSS properties.
