# PGR102 - Introduction to Programming

Introduction to programming fundamentals, with JavaScript in the browser.

## Assignments

Assignments are graded either A-F or Pass/Fail.

- [Assignment 1](assignments/assignment-1/pgr102h26-assignment/): Group assignment on JavaScript. The HTML, CSS and
  images were provided, and we wrote the JavaScript that brings a small turn-based game to life, where three heroes 
  fight a dragon.
  - **Core game logic:** Click events on the heroes, damage calculation, and the dragon counter-attacking a random hero.
  - **Techniques:** Functions, arrays of objects, `Math.random`and `Math.floor`, `if`/`else`, `alert`, and removing elements
    from the page.
  - **Win and lose conditions:** Detecting when all heroes are dead or the dragon is defeated.
  - **Extra features:** Hero and dragon names and HP shown on the page, life bars that shrink as HP drops, and defeated heroes      removed from the page.

  **Grade:** Pass
